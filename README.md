# 🛸 GALAXY SURVIVOR — инструкция по публикации в Яндекс Игры

## 📁 Состав игры
- `index.html` — главный файл (входная точка)
- `game.js` — весь игровой движок
- `style.css` — стили и меню
- `icon.svg` — иконка 512×512 (сделай из неё PNG/JPG 512×512)

## 🧪 Как протестировать локально
Просто открой `index.html` в браузере (Chrome/Edge/Firefox). Игра запустится и без SDK — реклама и лидерборд просто отключены.

Яндекс Игры **требуют HTTPS**. Для локального теста можно запустить локальный сервер (см. `start_server.bat`).

## 🚀 Как загрузить на Яндекс Игры
1. Зарегистрируйся как разработчик на https://games.yandex.ru/
2. Нажми «Добавить игру» → выбери тип **HTML5**
3. Скопируй файлы `index.html`, `game.js`, `style.css`, `icon` в проект
4. Укажи в настройках:
   - **Загрузка**: index.html
   - **Иконка**: 512×512 (144×144 для чата игроков)
   - **Жанр**: Аркада / Экшен
5. Пройди модерацию (обычно 1–3 дня) и опубликуй

## 💰 Монетизация (уже встроена)
- **Баннерная реклама** — показывается постоянно во время игры
- **Полноэкранная реклама** — каждые 5 уровней, на босс-волнах, при выходе/рестарте
- **Rewarded-видео** — «Вернуться после смерти» за просмотр рекламы (самый дорогой формат!)

## 🏆 Лидерборд
Результаты отправляются в лидерборд `galaxy-survivor`.
⚠️ Важно: создай лидерборд с **идентификатором `galaxy-survivor`** в настройках игры на Яндекс Играх (Контент → Лидерборды). Тип значения: **Число**.

## 💡 Советы для роста аудитории
- Обновления каждые 2–3 недели (бонусы за ежедневные задания)
- Название и описание — на русском, ключевые слова: «космос», «выживание», «орда»
- Скриншоты из игры — на главный экран

## ⚙️ Дополнительно
- В `game.js` переменная `'galaxy-survivor'` встречается 2 раза — это ID лидерборда. Можешь поменять на свой.
- Управление: WASD / стрелки / тач-джойстик. Пробел — заморозка врагов.
